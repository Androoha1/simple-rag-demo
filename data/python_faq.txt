Python is a high-level, interpreted programming language known for its simple and readable syntax. It was created by Guido van Rossum and first released in 1991.

A Python list is an ordered, mutable collection that can hold items of any type. Lists are defined with square brackets, e.g. my_list = [1, 2, 3]. You can append items with my_list.append(4) and access elements by index.

A Python dictionary is an unordered collection of key-value pairs. Dictionaries are defined with curly braces, e.g. my_dict = {"name": "Alice", "age": 30}. Keys must be unique and immutable.

A Python virtual environment (venv) is an isolated Python environment that allows you to install packages for a specific project without affecting the global Python installation. You create one with python -m venv .venv and activate it with .venv\Scripts\activate on Windows or source .venv/bin/activate on Linux/macOS.

pip is the standard package manager for Python. You use pip install package_name to install packages, pip uninstall package_name to remove them, and pip freeze to list installed packages. Requirements can be saved to a file with pip freeze > requirements.txt.

Python supports object-oriented programming through classes. A class is defined with the class keyword, and instances are created by calling the class. Python supports inheritance, allowing a class to inherit attributes and methods from a parent class.

Python functions are defined with the def keyword. Functions can accept positional arguments, keyword arguments, default values, and variable-length arguments using *args and **kwargs.

Python list comprehensions provide a concise way to create lists. For example, squares = [x**2 for x in range(10)] creates a list of squares from 0 to 81.

A Python tuple is an ordered, immutable sequence. Tuples are defined with parentheses, e.g. my_tuple = (1, 2, 3). Unlike lists, tuples cannot be modified after creation, making them suitable for fixed collections like coordinates or database records. You can access tuple elements by index, just like a list.

A lambda function in Python is a small anonymous function defined with the lambda keyword. For example, double = lambda x: x * 2 creates a function that doubles its input. Lambda functions are typically used with higher-order functions like map(), filter(), and sorted() where a short, one-off function is needed.
